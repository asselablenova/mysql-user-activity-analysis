# Анализ пользовательской активности в MySQL

## Этот проект представляет собой практическое задание по анализу данных с использованием **SQL (MySQL)**. В рамках проекта решаются задачи по исследованию пользовательской активности, расчету метрик вовлеченности, фильтрации агрегированных данных и оценке времени жизни пользователей на платформе (Lifetime / LT).

## 🛠 Стек технологий
* **СУБД:** MySQL
* **Инструменты:** MySQL Workbench / DBeaver

---

## 📋 Структура данных и задачи

База данных `miniproject1` содержит таблицу `users` со следующими ключевыми полями:
* `user_id` — идентификатор пользователя
* `date` — дата активности
* `view_adverts` — количество просмотренных рекламных объявлений

### Выполненные аналитические запросы:

1. **Подсчет уникальных пользователей за период:**
   * *Задача:* Вывести одним числом количество уникальных пользователей, проявивших активность в период с `2023-11-07` по `2023-11-15`.
2. **Самый активный пользователь:**
   * *Задача:* Определить пользователя, который за весь период суммарно посмотрел наибольшее количество рекламных объявлений.
3. **Пиковый день по средним просмотрам:**
   * *Задача:* Найти день с наибольшим средним количеством просмотров рекламы на одного пользователя (учитывались только дни с посещаемостью более 500 уникальных пользователей).
4. **Расчет продолжительности присутствия (Lifetime / LT):**
   * *Задача:* Рассчитать показатель LT для каждого пользователя как разницу между датой последней и первой активности (+1 день) с сортировкой по убыванию.
5. **Топ пользователь по стабильной активности:**
   * *Задача:* Найти пользователя с самым высоким средним числом просмотров рекламы за день среди тех, кто был активен как минимум в течение 5 разных дней.

## 💻 Пример кода (SQL)

Ниже приведен фрагмент решения задачи на поиск пользователя с наибольшим числом просмотров и расчет LT:

```sql
-- Пример: Расчет LT (Lifetime) пользователей
SELECT 
    user_id, 
    (DATEDIFF(MAX(date), MIN(date)) + 1) AS LT
FROM users
GROUP BY user_id
ORDER BY LT DESC;
